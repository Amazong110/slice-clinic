# Northvale Clinic

English demo site for a primary-care / family-medicine clinic template.

- Cold white UI · near-black display type · seafoam accent
- Local seed when Prismic is unavailable (`lib/seed.js`)
- Images: Unsplash → `public/prismic-mirror/` (see `provision/UNSPLASH-CREDITS-clinic.md`)

```bash
export PATH="/home/ubuntu/node24/bin:$PATH"
npm install
npm run dev
```

Demo content is fictional. This site does not provide medical advice.
